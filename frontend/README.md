# GoalForge Frontend

Next.js application for GoalForge. Run from this directory with:

```bash
npm run dev
```

Run one Next.js process for this checkout at a time. Stop the development
server before running `npm run build`; both commands write generated files to
`.next`. If development output reports a missing chunk after an interrupted
build or restart, stop the server, remove only the generated `frontend/.next`
directory, and run `npm run dev` again.
